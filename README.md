DealVerdict — a static Black Friday deal finder with 31 real deals checked at their stores on Nov 27, 2026. Every deal shows its product, store, store link, sale price, usual price, discount, check time and source, plus an honest TRUE DEAL / GOOD PRICE / ROUTINE SALE verdict. Search and filters by category, store and discount, sorting by discount or savings, and a detail page per deal with the evidence behind its verdict.

## Run it

```sh
python3 -m http.server 8080 --directory app
# open http://localhost:8080
```
